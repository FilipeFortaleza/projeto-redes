# jogo de damas
o projeto é um jogo de damas com dois jogadores.
Para jogar ambos devem abrir o programa em seus respectivos computadores, um deve iniciar o servidor com "python servidor.py" no terminal do compilador usado. Após isso, será necessário descobrir o IP do usuário hospedando o servidor, no caso de um windows pode abrir o prompt de comando, digitar "ipconfig" procurar o ipv4 e anotar o valor. então os jogadores deverão iniciar o cliente com "python cliente.py" e digitar o IP anotado previamente, após isso o jogo vai iniciar (obs: só funciona caso ambas as máquinas estejam na mesma rede)
